# Weekly Progress Report Template

Copy this file to `Docs/Week<NUMBER>Progress.md` at the beginning of a milestone week.

```markdown
# Week <NUMBER> Progress Report

**Project:** Game Frontier
**Period:** YYYY-MM-DD to YYYY-MM-DD
**Target platform:** Windows and macOS desktop
**Baseline commit:** <hash>

## Goal

<One paragraph describing the player-facing outcome for this week.>

## Planned acceptance criteria

- [ ] <Criterion 1>
- [ ] <Criterion 2>

## Completed

- <Player-visible change or documented decision>

## Validation

- Unity version: <version>
- Scenes checked: <scenes>
- Editor checks: <result>
- Standalone checks: <result or not yet run>
- Evidence: <screenshots/logs/links>

## Decisions and architecture notes

- <Decision and its reason; link to the relevant design or technical document.>

## Known limitations and risks

- <Known issue, affected scope, and follow-up.>

## Next week

- <Small number of prioritized outcomes.>

## Commits and releases

- <Commit or PR links>
- <Release/tag, if any>
```

Reports should describe outcomes and evidence rather than a diary of every attempt. If planned work was not completed, state why and carry it forward explicitly.
